The public command is `lattice`. `search`, `inspect`, and `context` are implemented.

```text title="Phase 1 commands"
lattice init
lattice search <query>
lattice inspect <id-or-name>
lattice context <task>
```

Each command accepts `--root <path>` and `--json`; `--help` and `--version` are global. Every query
runs fresh static analysis, then safely refreshes `.lattice/cache/reuse-index.json`. It does not write
application source.

JSON output uses schema version 1 and contains `command`, `result`, and `truncated`. Search returns
ranked evidence-backed candidates. Inspect returns explicit found, ambiguous, or not-found resolution
plus related imports, usages, evidence, and diagnostics. Context uses the core default budget of eight
items and 6,000 characters.

`lattice init` is not implemented yet. Its dry-run, skip-existing, and explicit-force file contract
remains a separate slice.

- `search`, `inspect`, and `context` run fresh bounded analysis and write only the validated generated
  Reuse cache. They support deterministic human output and schema-versioned JSON.
- Reuse core owns ranking, resolution, and context budgets. Analyzer owns root validation and cache
  writes. CLI owns parsing, output, and exit codes.
- `init` is not implemented. Do not claim it is available until its safe plan and write tests pass.

Rules:
- Reuse analyzer and core public interfaces. Do not create a parallel index, serializer, cache path,
  ranking rule, root resolver, or output schema version.
- Keep stdout for results and stderr for errors. Preserve exit code 0 for success, 2 for usage errors,
  and 1 for analysis failures.
- Do not change accepted ADRs. Stop for a human decision if a new write location, dependency, network
  path, or unsupported evidence claim is needed.

Required tests:
- Run `pnpm --filter @latticeos/cli test`.
- Test human and JSON output, root handling, error streams, cache confinement, determinism, and every
  added command or option.
- Run complete repository gates before claiming the slice complete.

Documentation:

  in the same change.
- Keep prose factual and direct when applying the Humanizer rules.

Stop conditions:

Completion evidence:
