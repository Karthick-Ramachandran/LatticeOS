---
title: Local npm pre-release
description: Create and evaluate one bundled LatticeOS CLI tarball without publishing it.
---

LatticeOS can create one local pre-release tarball for outside evaluation. It is not published to npm.
The artifact is `@latticeos/cli@0.1.0-rc.0`, includes the compiled analyzer/runtime closure, and
requires Node.js 22 or newer.

This is a narrow distribution path, not a support claim for every repository. The local Reuse
benchmark has recorded candidate evidence on the controlled fixture. AC-16 quality gates pass, but
Phase 1 still needs qualified proof that treatment context reached the agent unchanged.

## Create the artifact

Run this in a checked-out LatticeOS repository after dependencies are installed:

```bash title="Create one local pre-release tarball"
pnpm release:pack
```

The command rebuilds the required packages, stages a fixed dependency closure in an OS temporary
directory, and prints the tarball's absolute path. It does not call `npm publish`, read a token, or
accept an output path. Keep the printed path while sharing the file; OS temporary-file cleanup can
remove it later.

## Install it for a local evaluation

Install the tarball in a scratch directory, not in the repository you want to analyze. Use the
absolute path printed by `pnpm release:pack`.

```bash title="Install without registry access or lifecycle scripts"
mkdir latticeos-eval
cd latticeos-eval
npm init --yes
npm install --offline --ignore-scripts --no-audit --no-fund --no-save --package-lock=false /absolute/path/latticeos-cli-0.1.0-rc.0.tgz
```

Then analyze a repository by passing its absolute path. Analysis reads source statically and writes
only `.lattice/cache/reuse-index.json` inside that repository.

```bash title="Run the installed CLI"
./node_modules/.bin/lattice --version
./node_modules/.bin/lattice --root /absolute/path/to/ui-repository search Button --json
```

The package does not execute the analyzed repository's source or configuration. It does not rewrite
application source. `lattice init --write` is the separate, explicit command that can create
`.lattice/config.json`.

## Verify the artifact inside LatticeOS

```bash title="Run the package proof"
pnpm test:package
```

The proof builds the packages, checks the staging filesystem boundary, runs `npm pack --dry-run
--offline`, installs the single tarball with scripts disabled into a minimal external fixture, and
checks version, help, JSON search, source preservation, and the generated cache. See [the full
artifact proof](/docs/cli/packed-consumer) for the legacy workspace check that remains part of this
gate.
