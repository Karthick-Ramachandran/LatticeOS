<Callout title="Implemented" type="info">
  `analyzeProject` performs one project discovery pass, runs the bounded React and Tailwind bridges,
  and returns a validated schema-versioned `ReuseIndex`. Cache writes and CLI commands are still
  separate work.
</Callout>

## Use it

`analyzeProject` is the read-only entry point for the implemented evidence pipeline.

```ts title="Build an in-memory Reuse index"
import { analyzeProject, RepositoryRoot } from "@latticeos/analyzer";

const root = await RepositoryRoot.open("/workspace/product");
const result = await analyzeProject(root, {
  generatorVersion: "0.0.0",
  maxReactSourceFiles: 5_000,
  maxTailwindSourceFiles: 5_000,
});

if (result.truncated) {
  console.warn("Some evidence is unavailable. Inspect result.index.diagnostics.");
}

const index = result.index;
```

The function returns repository-relative, sorted data only. It does not write `.lattice`, import a
consumer config, execute source, call the network, or create a cache file.

## What the index combines

`analyzeProject` calls `detectProject` once. It passes that shared discovery result to the React and
Tailwind bridges, then `buildReuseIndex` combines their facts with discovery evidence.

| Source | Index fields |
| --- | --- |
| Project discovery | `project`, `packages`, marker evidence, and discovery diagnostics |
| React bridge | Components, props, imports, usages, composition, React evidence, and diagnostics |
| Tailwind bridge | Theme tokens, exact repeated static bundles, Tailwind evidence, and diagnostics |

Before returning, LatticeOS sorts the full index and runs core validation. If two producers emit the
same evidence ID with different content, assembly stops instead of choosing one silently.

## Incomplete evidence

`result.truncated` is true if discovery, React selection, or Tailwind selection reached a limit or
skipped an unreadable input. The index remains valid and contains only the evidence that was admitted.
Its diagnostics explain the missing scope. A caller must not present a partial index as a complete
component inventory.

The default generator version is `0.0.0-dev`. Pass a trimmed, non-empty `generatorVersion` from a
packaged caller when the output becomes user-facing. Version strings reject control characters and
values longer than 128 characters.

## Test evidence

`fixtures/goldens/reuse-index.next-workspace.golden.json` proves the named workspace builds one
validated index with React components, evidence links, Tailwind tokens, and repeated bundles.
The analyzer tests also prove repeat output serializes byte-for-byte and that a source cap produces a
valid partial index with a diagnostic.

Run `pnpm --filter @latticeos/analyzer golden:update`, inspect the snapshot diff, then run
`pnpm --filter @latticeos/analyzer test`.
