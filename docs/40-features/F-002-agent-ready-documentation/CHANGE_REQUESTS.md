# Change Requests: Agent Ready Documentation

Record accepted changes to the feature requirements here.

## CR-001: Fumadocs and copy-ready prompts

Status: Accepted on 2026-08-29.

Use Fumadocs to document features during implementation. Every feature guide must include a single
copy-ready prompt that gives an agent enough repository context, scope, steps, tests, stop conditions,
and completion evidence to implement the feature without chat history.

## CR-002: Humanizer prose review

Status: Accepted on 2026-08-29.

Apply the supplied Humanizer editing rules to explanatory prose. Do not rewrite or soften technical
contracts, facts, code, commands, frontmatter, links, acceptance criteria, or test evidence.
